# Security policy

## Reporting a security concern

For potential security vulnerabilities affecting Glounix Factory's **public website or public materials**, contact **info@simorghhub.com** with the subject **Confidential Security Report — Glounix**.

Please provide a concise description, affected public URL, reproduction steps if safely available, and an appropriate contact method. Do **not** include secrets, personal information, or live exploit payloads in public GitHub issues.

Do not test systems you do not own or have explicit authorization to test. Avoid disruption, access to other users' data, or disclosure of confidential details.

## Scope

This public repository does not contain the proprietary application code. Its presence does not imply an invitation to assess private infrastructure or unreleased products.

No response-time guarantee, bug-bounty program, or production SLA is currently advertised here.
