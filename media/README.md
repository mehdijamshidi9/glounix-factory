# Approved public media

Only publish official, approved Glounix brand assets and public-safe screenshots or demonstrations here.

Guidelines:
- Never invent or substitute a logo or favicon.
- Include source/approval provenance for every published asset.
- Use synthetic or explicitly authorized data in all UI captures.
- Remove secrets, internal addresses, project identifiers, private customer details, and sensitive metadata.
- Do not upload internal engineering diagrams that reveal proprietary models or compiler internals.
- Include descriptive alt text when embedding images in documentation.

This directory intentionally ships **without media files** until official assets are supplied and approved.
