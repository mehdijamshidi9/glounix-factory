# Public development updates

This directory is reserved for **approved, factual, high-level development announcements**. It is not an automatic mirror of private commits, development-capture logs, or issue trackers.

Updates should be short, dated, and supported by evidence appropriate for public release. Each update should identify whether a capability is a completed internal milestone, a demonstrated feature, or planned work.

The official website is the intended canonical home for longer announcements: https://factory.simorghhub.com

**Editorial rule:** No article is published here solely because a development agent reported success. A human reviewer must approve the exact public-safe content and any attached media.

No launch or customer-success claims are made in this directory at this time.
